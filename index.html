The International Workshop on Agentic AI Security (AAS 2027)

AAS 2027 is organized with the International Conference on Next Generation Cyber Security (NGCS 2027), taking place on March 15–18, 2027 in San Antonio, Texas, USA.

The workshop brings together researchers and practitioners working on the security of autonomous AI agents: systems that plan, use tools, browse, write and execute code, hold memory, and act on behalf of users and organizations, as well as agents built to defend networks and systems.

Call for Papers

Submit original work on securing autonomous AI agents and using agents to secure systems.

AAS 2027 invites researchers, practitioners, and industry experts to submit original contributions on the security of agentic AI. When LLM-based agents are given tools, credentials, memory, and the ability to act, model weaknesses become system weaknesses: injected instructions can trigger real actions, permissions can be abused, and multi-agent pipelines can propagate compromise. At the same time, security teams are deploying agents for detection, triage, penetration testing, and response.

// SUBMISSION TYPES

The workshop welcomes theoretical, empirical, experimental, and applied work, including full research papers, short papers, position papers, case studies, tool demonstrations, datasets, benchmarks, red-team reports, and lessons learned from real-world deployments.

// SCOPE

AAS 2027 focuses on two closely connected research directions.

DIRECTION 01 · PROTECT THE AGENT security ──▶ agent

Security for agentic AI

The first is security for agentic AI, covering threats such as direct and indirect prompt injection, tool and plugin misuse, memory poisoning, excessive agency, and multi-agent collusion, together with defenses including sandboxing, least-privilege tool access, policy enforcement, monitoring, human oversight, and secure protocols for agent-to-tool and agent-to-agent communication.

DIRECTION 02 · AGENTS AS DEFENDERS agent ──▶ security

Agentic AI for security

The second direction is agentic AI for security, focusing on how autonomous and semi-autonomous agents can strengthen cyber defense through threat hunting, alert triage, vulnerability discovery, automated penetration testing, secure code repair, and incident response, and on how to evaluate their reliability, safety, and accountability in operational settings.
